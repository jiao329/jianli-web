# 简历工坊

一个无需后端的在线简历设计工作台，支持：

- 个人信息、简介、工作经历、教育经历、技能与项目编辑
- 工作经历动态添加 / 删除
- 经典、现代、极简、编辑、单色、柔和六种可实时切换的模板
- 字体类型与正文大小调整
- 姓名、职位、联系方式和表头整体的独立位置、字号与间距调整
- 页面边距、模块间距、行高、分栏和标题分隔线设置
- 自动保存到浏览器 `localStorage`
- 系统打印导出 PDF、画布导出 PNG、分享链接复制
- 桌面端双栏编辑，移动端纵向预览

## 本地运行

项目是静态页面，可直接使用任意静态服务器打开：

```bash
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173`。
